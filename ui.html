Setup & workbook

Master workbook

Excel is the source of truth. Close the workbook in Excel before making changes here. The app backs it up before each save, and detects conflicting edits. While the app is running, saved Excel edits are detected automatically. Close Excel to allow the updated links to be written back. Product-name, item-name, manufacturer, model, and finish changes trigger lookup; quantity and notes changes do not.

Product search

Copy .env.example to .env in the project folder. Set SEARCH_PROVIDER=brave and add your own BRAVE_API_KEY, then restart the app. SerpAPI and Claude are also supported by the existing lookup script.

Keep API keys only in your local .env file. Automatic search sends the manufacturer, model number, and product/item name to the provider, not client details. Provider charges may apply after saved product edits. Existing unchanged selections are not searched on first launch. Failed requests retry up to three times, then wait for a manual retry.

Presentation branding

Your supplied UH Homes wordmark and gold symbol are installed. Edit lookbook_config.json to adjust contact details or brand settings, then restart the app. The starter contact information is a placeholder—replace it before sending final presentations.

Excel import

Import replaces the master workbook after confirmation, preserving a timestamped copy in backups/. Use the same Projects, Selections, Manufacturers, and Lists sheets as the exported template. Maximum upload: 8 MB.

This version is for local use on one computer. It does not include accounts, shared hosting, or multi-user collaboration.
